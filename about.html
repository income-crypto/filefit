ABOUT US

Useful file tools, without the fuss.

Filefit is a collection of free image and PDF tools built for everyday tasks: compressing photos for online forms, resizing signatures, converting images, and creating or organizing PDFs.

The site aims to stay simple. There is no registration, no watermark, and no paid processing API. Your files are processed in your own browser, rather than uploaded to a Filefit server.

How it works

Image operations use standard browser technology. PDF operations use the open-source pdf-lib JavaScript library, served from the same Filefit domain and loaded only when required.

Contact

Questions, feedback or problems using Filefit? Email york.manak111@gmail.com or visit our contact page.

Limitations

Some browsers or very large files may run out of memory. Encrypted PDFs are not supported by the PDF tools. Image file-size targets are best-effort, not guaranteed.
