How to Extract Specific Pages from a PDF

Need just pages 2–4 or an individual document from a larger PDF? Learn how page ranges work, what to verify and when merging is the better tool.

✓ Free browser tools✓ Your files stay on your device✓ No signup

Extracting pages is different from splitting into separate files

Sometimes a PDF contains a long set of forms, notes or scanned documents, but you only need a few pages. With Filefit's PDF page extractor, you select the pages to keep and download one new PDF containing those pages. It does not generate a ZIP of individual single-page PDFs. If you need separate documents, repeat the process for each selection.

Filefit uses one-based page numbering: the first page in the PDF is page 1. A number in the printed footer of a scanned document may not match its PDF page index. Count from the first page of the actual PDF file, not from a chapter's printed number.

Extract pages with Filefit

  1. Open the free Split PDF tool in a modern browser.
  2. Select a single PDF file. The site processes the document in your browser; it is not uploaded to a Filefit conversion server.
  3. Type the pages or ranges you want to keep, for example 2-4, 7. Use commas to separate sections and a hyphen for an inclusive range.
  4. Choose Extract pages, then download the resulting PDF.
  5. Open the downloaded document and verify the pages, count, rotation, readable text and any important seals or signatures.

Practical situations

Send only the required pages of an application

If a portal requests pages 1–3 of an eight-page PDF, extract only those pages and check that the remaining PDF still contains the full forms and all visible details. Inspect the original portal's privacy and file-size rules separately.

Share a chapter or section of notes

Record the page range shown in the PDF viewer before extracting. Cover pages, indexes and blank scans can shift the page count. The correct section might be pages 12–17 even when the book prints 10–15 at the bottom.

Separate several receipts

If different receipts are on different pages, create a new PDF for each selection. The extractor creates one output at a time, so repeat it for other receipts rather than expecting automatic individual files.

Common mistakes and limitations

Why do I see the wrong page?

Check whether you used the printed page number instead of the PDF's actual page index. Also check that your starting file is the right version—added title pages and scans can shift every later position.

Will this remove confidential content permanently?

Extracting selected pages removes unselected pages from the new PDF, but this is not a secure redaction tool. If confidential information appears on a retained page, it remains visible. For legal or regulated documents, use a tool designed for secure redaction and verify the results.

What about password-protected or signed PDFs?

Encrypted PDFs are not supported by Filefit's PDF tools. Changing a digitally signed PDF can invalidate its signature, so preserve the original and follow the receiving organization's requirements. Some complex PDF features may not survive edits exactly as expected; always inspect the output.

Does extraction compress a large PDF?

Removing pages can reduce the file size, but extraction is not a dedicated PDF compression feature and a smaller result is not guaranteed. Files with embedded high-resolution images may remain large.

When to use Merge PDF instead

If you need to combine two or more existing PDFs into one document, use Merge PDF. If you have photos or screenshots that you want to put into a PDF, use Images to PDF. Filefit offers separate tools because these tasks are different.
