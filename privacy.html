Privacy Policy

Last updated: November 2, 2026

Files you process

Filefit processes selected images and PDFs locally inside your browser using JavaScript. The application does not intentionally upload your file contents to a Filefit server, create user accounts, or retain copies of processed files. Generated downloads are created locally.

External code and hosting

PDF functions load the open-source pdf-lib library from the Filefit website when needed. The code is hosted on the same domain; PDF contents remain in your browser. The hosting provider (Cloudflare Pages when deployed there) may process ordinary request metadata and security logs under its own policies.

Cookies and analytics

This source-code version does not set application cookies or include analytics or advertising scripts. If third-party advertising or analytics is added in the future, this policy must be updated beforehand to describe its data collection and any necessary consent controls.

Storage

Files are held temporarily in browser memory while you use a tool. Clearing the page removes that temporary state. Downloaded files are saved to the location you choose on your device.

Contact and changes

For privacy questions or enquiries about Filefit, contact york.manak111@gmail.com. You can also visit our Contact page. We may update this policy if the site's functionality or data practices change.
