How to merge PDFs in order

  1. Choose two or more PDF files from your device.
  2. Use the up and down controls to arrange your PDFs. Pages from each document are kept in that file's order.
  3. Click Merge PDFs and download the combined document.

Before combining important PDFs

Check that you have included every document and that the ordering is correct. Filefit copies the pages into a new PDF file; it does not edit the wording of individual pages or guarantee that interactive form features will remain editable.

Password-protected, damaged or unusually large PDFs may not process successfully. If a file is protected, unlock it using a trusted tool only if you are authorized to modify it. Keep your original files until you have verified the merged result.

Starting with JPG or PNG files instead? Follow our guide to combining images into a PDF before merging the resulting PDFs.

COMMON QUESTIONS

Merge PDF FAQs

Can I change the order of PDFs?

Yes. Arrange uploaded files using the up and down buttons before merging.

Can I merge a password-protected PDF?

Password-protected PDFs are not reliably supported. Use an authorized, trusted editor to unlock the file first.

Are the PDF files uploaded?

The merge operation runs locally in your browser. A PDF library is downloaded as code when needed, but the document data is not sent to that library's CDN.
